The first public release of AI-Geode: an AI player for Geometry Dash 2.2081 that plays classic levels by itself and learns from its own deaths.

**Requirements:** Geometry Dash 2.2081 on Windows, Geode 5.11.1 or newer.
**Install:** download `aqvose.ai-geode.geode` below, put it into `Geometry Dash/geode/mods/`, restart the game, open a level and press **F8**.

## New in v0.7.0: trajectory proximity
- Every predicted step measures how close the player's hitbox comes to deadly geometry, using the game's collision rectangles. Floors and blocks underfoot are not counted as danger.
- **Danger colours:** the predicted path is green where it is clear, then orange and red as it gets closer. A ringed marker shows the closest point, and yellow still means uncertain.
- **Decisions prefer clearance:** among safe timings the AI picks the one with more room. Near misses are penalised but still preferred over a collision.
- **Near-miss learning:** near misses are remembered per level, and reusable strategies keep the margin they passed with.
- New settings: *Danger Colours*, *Clearance in Decisions*, *Safe Clearance* (18), *Danger Clearance* (4).

## Everything else included (v0.1 – v0.6)
- Q-learning with failure analysis and timing experiments after each death. Memory is saved per level and can be exported, imported and reset.
- Trajectory prediction and a safety layer for every game mode, calibrated against the real game.
- Orb and dash-orb prediction (activate or skip). Speed, gravity, mode and size changes inside predictions.
- A whole-level map and analysis, strategic multi-jump planning, and a cross-level strategy library.
- Status panel, path overlays, a level understanding view, and a three-tab AI popup in the pause menu.

See [changelog.md](https://github.com/ooune/AI-Geode/blob/v0.7.0/changelog.md) for every version.

## How this build was checked
- This release file was built by GitHub Actions from the `v0.7.0` tag. The core test suite (128 tests, 2,881 checks) passed in the same run. Its SHA-256 is in `SHA256SUMS.txt`.
- In game (GD 2.2081, Geode 5.11.1), v0.7.0 loads and plays, and the danger colours, clearance label and per-attempt `Proximity:` log were confirmed working.
- Proximity scoring increases the margin the AI flies with in the simulator. A gain in survival or progress has **not** been shown yet, in the simulator or in game ([validation report](https://github.com/ooune/AI-Geode/blob/v0.7.0/docs/validation/V070-VALIDATION.md)).

## Known issues
- **Jump pads and slopes are not simulated**, so levels that need a pad (for example the start of *Hexagon Force*) can stall the AI at that spot.
- Hitbox sizes for some modes are estimates. Saws and rotated hazards use their bounding rectangles. Better hitboxes are planned for v0.8.0.
- Platformer levels are not supported, and in 2-player levels only player 1 is controlled.
- Levels the AI completes in normal mode count as your completions. Use *Practice Mode Learning* to avoid that.
